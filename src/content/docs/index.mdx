## Why issuerd

issuerd is an identity control plane for the agentic era: it governs human and
non-human identities alike — users, services, workloads and AI agents — with
least-privilege, short-lived, sender-constrained tokens and phishing-resistant
authentication by default.

<CardGrid stagger>
  <Card title="OpenID Certified OIDC/OAuth2" icon="approve-check-circle">
    <a href="https://openid.net/certification/certified-openid-connect-implementations/"><img src="/images/openid-certified.jpg" alt="OpenID Certified" width="160" /></a>

    The official OpenID Foundation registries list **10 OP profiles on v0.1.17**
    plus **RP-Initiated Logout OP on v0.1.19** ([OIDC](https://openid.net/certification/certified-openid-connect-implementations/),
    [logout](https://openid.net/certification/certified-openid-providers-for-logout-profiles/)).
    The accepted submissions used the hosted conformance suite (release v5.3.3).
    Separately, the self-hosted release v5.3.2 engineering matrix passes 43 test
    plans, 612 modules and 31,000+ conditions with 0 failures and 0 unexpected
    warnings. Every [release](https://github.com/issuerd/issuerd/releases) ships
    an attested conformance report bundle. Advanced OAuth 2.1 capabilities included:
    PAR, JAR/JARM, RAR, DPoP, CIBA, token exchange, dynamic client registration.
  </Card>
  <Card title="Keycloak-compatible" icon="puzzle">
    The realm model, role claims (`realm_access` / `resource_access`), the Admin
    REST API shape, adapter-config downloads, and `kc_idp_hint` behave the way your
    existing Keycloak integrations expect. Every deliberate difference is
    documented in `tests/KEYCLOAK_DIFFS.md`.
  </Card>
  <Card title="Fast and small" icon="rocket">
    Faster than Keycloak 26.7 in every measured k6 scenario — up to 7.8× the
    throughput, ~6× less memory, and an 8.7× smaller image. One self-contained
    Rust binary; `#! [forbid(unsafe_code)]` across the whole workspace.
  </Card>
  <Card title="Scales horizontally" icon="server">
    Shared state lives in PostgreSQL + Redis, and storage-backed signing keys are
    shared by every node. Run a single binary or a multi-node cluster behind a
    load balancer — a two-node demo stack ships in the repo.
  </Card>
  <Card title="Built for AI agents" icon="star">
    First-class support for agentic workloads: DPoP sender-constrained tokens,
    RFC 8693 token exchange with per-call audience/scope attenuation — scoped
    credentials per tool call — and CIBA step-up approval that keeps a
    human-in-the-loop (HITL) over high-risk operations. End-to-end MCP guides
    and recorded demos included.
  </Card>
  <Card title="Federation &amp; MFA included" icon="padlock">
    LDAP, Active Directory, and Kerberos/SPNEGO user federation; identity brokering
    with Google, GitHub, and Microsoft; TOTP, WebAuthn/passkeys for
    phishing-resistant MFA, and email-code
    login. No enterprise edition — everything is in the open repository.
  </Card>
</CardGrid>
